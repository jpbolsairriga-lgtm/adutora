Itens do croqui

Desenhar: escolha a ferramenta e clique no mapa. Linhas/talhão: duplo clique ou Concluir termina; Backspace desfaz o último ponto; Esc cancela.
Editar: clique no item para selecionar e arraste os vértices. Clique com o botão direito num vértice para apagá-lo. Delete remove o item selecionado.
Encaixe: o círculo verde/amarelo mostra onde o ponto vai encaixar (componente, vértice ou meio do tubo). Componentes encaixados ficam conectados: arrastar a bomba leva o tubo junto. Segure Alt para desenhar sem encaixe.
Sistemas: peças do projeto (rosa) não se ligam às do recalque (laranja) — o X vermelho indica conexão proibida. A ligação entre os dois é pelo reservatório.
