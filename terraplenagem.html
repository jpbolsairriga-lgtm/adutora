🔑 Chave Google Maps API

A chave ativa o mapa satélite Google e o serviço de elevação — necessário para calcular corte e aterro.

  1. Acesse console.cloud.google.com e crie/selecione um projeto.
  2. Ative Maps JavaScript API e Maps Elevation API.
  3. Em Credenciais → + Criar Credencial → Chave de API, copie a chave.
  4. Cole a chave no campo acima e pressione ✓.
