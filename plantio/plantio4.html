🔑 Como obter a Chave Google Maps API

A chave ativa o mapa satélite Google (mais nítido) e a classificação de declividade. Sem ela, o satélite ESRI é usado.

  1. Acesse o Google Cloud Console: console.cloud.google.com
  2. Crie ou selecione um projeto (menu no topo).
  3. No menu lateral vá em APIs e Serviços → Biblioteca e ative as duas APIs:
    ✔ Maps JavaScript API ✔ Maps Elevation API
  4. Vá em APIs e Serviços → Credenciais → + Criar Credencial → Chave de API.
  5. Copie a chave gerada (começa com AIzaSy…) e cole no campo acima.
⚠ A chave requer uma conta com faturamento ativado no Google Cloud. O Google oferece US$ 200 de crédito gratuito por mês — suficiente para uso profissional normal sem custo.

Para restringir o uso da chave, em Credenciais → Editar Chave adicione a URL deste app como restrição de HTTP referrer:
https://jpbolsairriga-lgtm.github.io/*

📡 Proxy SRTM/ASTER/Mapzen (opcional)

O app já cruza duas fontes de elevação gratuitas automaticamente (Google + Open-Meteo/Copernicus). Esse proxy é OPCIONAL — adiciona mais 3 fontes gratuitas (SRTM, Mapzen e ASTER) pra uma fusão mais precisa, do jeito descrito no vídeo de referência. Sem ele, o app continua funcionando normalmente, só com menos fontes.

Por que precisa disso: o serviço que fornece SRTM/Mapzen/ASTER (OpenTopoData) não permite chamada direta do navegador (bloqueio de CORS) — precisa de uma pontezinha simples entre o app e ele. Um Cloudflare Worker gratuito resolve isso em ~2 minutos, sem cartão de crédito.

  1. Acesse dash.cloudflare.com e crie uma conta grátis (só email) se não tiver.
  2. No menu lateral: Workers & Pages → Create → Create Worker.
  3. Dê um nome (ex: irriga-dem-proxy) e clique em Deploy.
  4. Clique em Edit code, apague tudo e cole o código abaixo, depois Save and Deploy.
export default {
  async fetch(request) {
    const url = new URL(request.url);
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: {
        'Access-Control-Allow-Origin': '*',
        'Access-Control-Allow-Methods': 'GET, OPTIONS',
        'Access-Control-Allow-Headers': 'Content-Type',
        'Access-Control-Max-Age': '86400'
      }});
    }
    if (!url.pathname.startsWith('/v1/')) {
      return new Response('Use /v1/<dataset>?locations=lat,lng', { status: 400 });
    }
    const destino = 'https://api.opentopodata.org' + url.pathname + url.search;
    const resp = await fetch(destino, { cf: { cacheTtl: 604800, cacheEverything: true } });
    const corpo = await resp.text();
    return new Response(corpo, { status: resp.status, headers: {
      'Content-Type': 'application/json',
      'Access-Control-Allow-Origin': '*',
      'Cache-Control': 'public, max-age=604800'
    }});
  }
};
  1. Vai aparecer uma URL tipo https://irriga-dem-proxy.SEU-SUBDOMINIO.workers.dev — cole ela no campo "Proxy SRTM/ASTER/Mapzen" da aba Início.
⚠ O plano gratuito do Cloudflare Workers cobre até 100.000 requisições por dia — muito acima do uso normal deste app.
